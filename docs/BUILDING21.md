## 🔖 จุดย้อนกลับ (safety point) — จำไว้ให้ดี

**ก่อน Building 21 เข้ามาแตะอะไร เกมหลักอยู่ที่คอมมิตนี้:**

```
7f87c95
```

สถานะ ณ จุดนั้น: **เกมเล่นจบได้จริง ขึ้นเว็บแล้ว** รวมงานถึงรอบ 10.17 (รื้อหน้า Intel) + แก้ชื่อ Lia Valerius
เทสทุกชุดผ่านหมด

**ถ้างานเละ ย้อนกลับด้วยคำสั่งนี้:**

```bash
git fetch origin
git reset --hard 7f87c95      # ทิ้งงานหลังจุดนี้ทั้งหมด
git push --force-with-lease origin claude/folder-structure-planning-0003vf
```

**อยากดูก่อนว่าต่างจากตอนนี้ตรงไหน** (ไม่แตะอะไรเลย):

```bash
git diff 7f87c95 --stat        # ไฟล์ไหนเปลี่ยนบ้าง
git log --oneline 7f87c95..HEAD  # คอมมิตอะไรเพิ่มมาบ้าง
```

**ย้อนแค่ไฟล์เดียว** (ปลอดภัยกว่า ใช้อันนี้ก่อนเสมอถ้าพังแค่จุดเดียว):

```bash
git checkout 7f87c95 -- src/config.js
```

> ⚠️ `reset --hard` + `force` **ลบงานที่ทำหลังจุดนี้ทิ้งถาวร** ทั้งของแชต A และ B
> ห้ามทำเอง **ต้องให้เจ้าของสั่งเท่านั้น** และต้องบอกอีกแชตก่อนด้วย
> ถ้าพังไม่มาก ให้แก้เป็นจุด ๆ หรือ `git revert` คอมมิตที่ผิดแทน — ไม่ลบประวัติ ปลอดภัยกว่ามาก

*(ลอง tag ชื่อ `v1.0-before-dlc` ไว้แล้ว แต่ push ขึ้น GitHub ไม่ได้ — proxy ของ session อนุญาตให้ push ได้แค่ branch ที่กำหนด ไม่รวม tag*
*เพราะงั้น **เลขคอมมิตด้านบนคือของจริงที่ต้องจำ** ตัวคอมมิตอยู่บน GitHub ถาวรแล้ว ไม่หายไปไหน)*

## กติกาการใช้สมุดเล่มนี้

1. **ก่อนเริ่มงาน** — `git fetch origin` แล้วอ่านไฟล์นี้ ดูว่าอีกฝั่งกำลังจับไฟล์ไหนอยู่
2. **ก่อนจะแตะไฟล์ที่ใช้ร่วมกัน** — จองในตาราง "ไฟล์ที่ใช้ร่วมกัน" ด้านล่างก่อน push
3. **ทุกครั้งที่ push** — เขียนลงท้าย "บันทึกงาน" ว่าทำอะไรไปแล้ว
4. **มีคำถามถึงอีกฝั่ง** — เขียนใน "คำถามค้าง" แล้ว push แล้ว**บอกเจ้าของให้ไปสะกิดอีกแชต**
   (สองแชตไม่เห็นกันเอง ไม่มีใครมาเตือน ต้องให้เจ้าของเป็นคนบอก)
5. **ห้ามลบของที่อีกฝั่งเขียน** — ขีดฆ่าหรือทำเครื่องหมาย ✅ แทน

## ✅ ทางเข้าเกมมีให้แล้ว — แชต A ทำไว้ให้ ไม่ต้องทำเอง

กด Play ในเมนูหลัก → มาหน้า **`SELECT OPERATION`** ให้เลือกโหมด
ตอนนี้มี 2 รายการ: **Main** (เล่นได้เต็มที่) และ **Building 21**

**Building 21 ไม่ได้ล็อกกดไม่ติดอีกแล้ว (อัปเดตล่าสุด)** — เลือกได้ปกติ แต่กด PLAY แล้วต้อง
**ใส่รหัสผ่าน 15 หลักก่อนถึงจะเข้าได้** (เจ้าของสั่ง) ใส่ถูกครั้งเดียวเครื่องนั้นจำไว้ ไม่ต้องพิมพ์ซ้ำ
ตอนนี้ใส่รหัสถูกแล้วจะเจอ **หน้าเปล่า** (ยังไม่ต้องทำเนื้อหาอะไร เจ้าของสั่งไว้ชัด)

**พอ DLC พร้อมเล่นจริง เปิดใช้แค่ 1 จุด อยู่ใน `src/ui/screens.js`:**

- ฟังก์ชัน `onModeStart(modeId)` ใน `initScreens()` — ตอนนี้ทุกโหมดที่ไม่ใช่ `'main'` (รวม Building 21
  หลังใส่รหัสถูก) ตกไปที่ `showBlank(...)` เป็นค่าเริ่มต้น **แก้เป็น `else if (modeId === 'building21') ...`**
  ให้ชี้ไปที่ฟังก์ชันเริ่มเกมของ DLC แทน

*(ไม่ต้องแตะ `GAME_MODES` แล้ว — Building 21 เปิดให้เลือกได้ตั้งแต่ตอนนี้ ไม่ได้รอ DLC เสร็จเหมือนก่อน)*

> ⚠️ **`screens.js` เป็นไฟล์ร่วม ต้องจองก่อนแตะ** (ดูตารางจองด้านบน)
> แต่จุดนี้เล็กมาก **แนะนำให้แชต A เป็นคนต่อให้ตอน merge** จะได้ไม่ต้องจอง
> Building 21 แค่บอกมาว่า "ฟังก์ชันเริ่มเกมของ DLC ชื่ออะไร อยู่ไฟล์ไหน" ก็พอ
>
> **รหัสผ่านจริงอยู่ที่ `CONFIG.dlcAccessCode`** (`src/config.js`) — ถ้า Building 21 อยากรู้รหัส
> หรืออยากเปลี่ยนรหัส ต้องถามเจ้าของหรือแชต A เท่านั้น **ห้ามเขียนรหัสซ้ำไว้ที่ไฟล์อื่น**
> (กฎเดียวกับตัวเลขบาลานซ์ — ค่าจริงอยู่ที่เดียว)

### 🔓 รหัสผ่านนี้เป็นของชั่วคราว — จะถูกถอดออกตอนเกมเสร็จ

ใส่ไว้แค่**กันคนทั่วไปเข้าเล่น Building 21 ก่อนที่ DLC จะทำเสร็จ** ไม่ใช่ระบบความปลอดภัยถาวรของเกม
พอ Building 21 พร้อมเปิดให้เล่นจริง (เนื้อหาเสร็จ ทดสอบแล้ว) **ให้ถอดหน้า ACCESS CODE ออก**
ให้กด PLAY แล้วเข้า Building 21 ได้ตรง ๆ เหมือน Main — จุดที่ต้องแก้อยู่ใน `renderModeSelect()`
(`ui/screens.js`): เอาแฟล็ก `gated: true` ออกจาก entry ของ `building21` ใน `GAME_MODES` ก็พอ
(โค้ดจะข้ามหน้ารหัสไปเรียก `onPlay` ตรง ๆ เหมือน Main ทันที ไม่ต้องแตะ `renderAccessCode` เลย)

**อย่าเพิ่งถอดเองตอนนี้ — รอเจ้าของสั่งเหมือนเดิม** แค่จดไว้ให้รู้ว่านี่เป็นด่านชั่วคราว ไม่ใช่ฟีเจอร์ถาวร

## นัดกันตอน merge (ยังไม่ถึงเวลา)

ตอน DLC เสร็จพร้อมขึ้นเว็บจริง ให้ทำตามนี้ **อย่าเพิ่งทำตอนนี้ รอเจ้าของสั่ง**

1. Building 21 เขียนใน "บันทึกงาน" ว่าพร้อม merge แล้ว + ลิสต์ไฟล์ร่วมที่แตะไปทั้งหมด
2. เจ้าของบอกแชต A
3. **แชต A เป็นคน merge** (เพราะ branch ตัวเองคือตัวที่ Pages เสิร์ฟ) แล้วรันเทสเดิมทั้งชุดซ้ำ
