### 3.3 Crowd Control — เคาะแล้ว

- ❌ **ไม่จองโซน** — Lyla ยังลงโซนที่ Robertson บัฟไว้ได้ (นี่คือคอมโบหลักของเกม)
- ❌ **ไม่มีความเสี่ยงบาดเจ็บ** (ตัดทิ้งจากเอกสารเก่า)
- ✅ ต้นทุนจริง = **Robertson ทำ Search & Rescue ไม่ได้ 3 ชั่วโมง**

### 3.4 Scan Area — ระบบ 5 ช่อง

- Lia มี **5 ช่อง (stack)**
- ใช้ 1 ครั้ง = ลากลง 1 โซน = **−10 AP · −1 ช่อง**
- โซนไหนบัฟหมดอายุ (3 ชม.) → **คืนช่องให้ Lia +1**
- ช่องหมด (เหลือ 0) → **ไอคอนสกิลขึ้นกากบาท ลากไม่ขึ้น** รอจนมีช่องว่าง (ไม่มีคูลดาวน์เป็นชั่วโมง)
- ซ้อนโซนที่มี Scan อยู่แล้วไม่ได้

## 4. สูตรและการทอย

### 4.1 อัตราสำเร็จ

```
อัตราสำเร็จ = ฐาน จนท. + บัฟรวม − ความเสี่ยงพื้นที่ + (−20 ถ้า Injured)
เพดาน 99%
```

| ตัวประกอบ | ค่า |
|---|---|
| Robertson ฐาน | +75 |
| Lyla ฐาน | +90 |
| Crowd Control | +25 |
| Scan Area | +15 |
| Air Deploy | +15 |
| Injured | **−20** |
| โซนเทา | −10 |
| โซนเหลือง | −30 |
| โซนแดง | −55 |

### 4.2 ทอย 2 ชั้น (ยืนยัน — ทิ้งวิธี `rollBetweenSuccessAnd100` ทิ้ง)

```
จนท. ทำงานครบเวลา
   ↓
ชั้น 1: roll(1-100) <= อัตราสำเร็จ ?
   ├─ ใช่  → สำเร็จ → ไปชั้น 2 → ปลอดภัย 100% (ไม่ทอยอันตราย)
   └─ ไม่  → ล้มเหลว → ทอยอันตราย
```

**ชั้น 2 — ระดับความสำเร็จ (บัฟไม่มีผลกับชั้นนี้)**

| ระดับ | %ช่วยชีวิต | Robertson | Lyla |
|---|---|---|---|
| 🌟 สูงสุด | 99% คงที่ | 20% | 35% |
| ⭐ สูง | สุ่ม 90–98% | 25% | 30% |
| ✦ ปานกลาง | สุ่ม 70–89% | 35% | 25% |
| ▪ ต่ำ | สุ่ม 50–69% | 20% | 10% |

```
รอด = floor(trapped × %ช่วยชีวิต)
ตาย = trapped − รอด        ← ที่เหลือตายหมด
trapped = 0 · โซนเป็นเขียว
```

### 4.3 ทอยอันตราย (เฉพาะตอนล้มเหลว)

```
โอกาสอันตราย = ค่าพื้นฐานโซน × (1 + ชั่วโมงปัจจุบัน ÷ 72)   เพดาน 50%
มี Alert Allied → 0% เสมอ
```

| โซน | ค่าพื้นฐาน |
|---|---|
| เทา | 5% |
| เหลือง | 15% |
| แดง | 30% |

**ทอยติด →** ปกติ → 🩹 Injured (ฟื้น 3 ชม.) · Injured อยู่แล้ว → 💀 Unconscious (ฟื้น 4 ชม.)

### 4.4 การตายตามเวลา

```
ตายต่อลูป = initial ÷ อายุโซน
อายุโซน: แดง 48 ลูป (24 ชม.) · เหลือง 96 ลูป (48 ชม.) · เทา 144 ลูป (72 ชม.)

ถ้าโซนนั้นมี Scan Area อยู่ → ตายต่อลูป × 0.5
```

เก็บ `trapped` เป็นทศนิยม · แสดงผลปัดลงเป็นจำนวนเต็ม

## 5. Last Stand (Robertson)

### 5.1 เงื่อนไขเข้าสถานะ

ทั้ง 3 ข้อพร้อมกัน:
1. **Lyla อยู่สถานะ Unconscious**
2. **Robertson อยู่สถานะ Injured**
3. **Robertson ทอยอันตรายติดอีกครั้ง** (ปกติจะกลายเป็น Unconscious → เกมเข้า CRITICAL)

→ **แทนที่จะหมดสติ Robertson เข้าสถานะ Last Stand** · เกม**ไม่**จบ · ถือว่า**ไม่บาดเจ็บ** (ไม่มีโทษ −20)

**ใช้ได้ครั้งเดียวต่อเกม** — หลังจากนั้นถ้าโดนรอบสองก็หมดสติตามปกติ

### 5.2 ผลระหว่าง Last Stand

| รายการ | ค่า |
|---|---|
| ระยะเวลา | **10 ชั่วโมงในเกม** |
| สไปรต์ | `Field-op-robertson-finalstand.png` |
| ค่า AP | **ฟรีทุกสกิล (0 AP)** |
| โซนที่ลงได้ | **ทุกโซน รวมโซนแดง** |
| เวลาทำงาน | เทา 1 · เหลือง 2 · **แดง 3** ชั่วโมง |
| Crowd Control | **ใช้ไม่ได้** |
| สถานะบาดเจ็บ | ล้างทิ้ง ถือว่าปกติ |

### 5.3 บัฟค้างข้ามการหมดอายุ

> ถ้า Robertson ลงพื้นที่ตอนยังอยู่ใน Last Stand แล้ว Last Stand หมดเวลาระหว่างที่เขายังทำงานอยู่
> **ภารกิจนั้นยังคิดด้วยเงื่อนไข Last Stand เดิม** (อัตราเดิม เวลาเดิม) จนกว่าจะจบงาน

*(นี่เป็นข้อยกเว้นเฉพาะ Last Stand — บัฟชนิดอื่นยังคิดตอนงานจบตามปกติ)*

### 5.4 จบ Last Stand

```
ครบ 10 ชม. → Robertson หมดสติทันที (Unconscious 4 ชม.)
   ↓
ถ้า Lyla ยังหมดสติอยู่ด้วย → เริ่มนับ CRITICAL 3 ชม. ตามปกติ
```

> ในทางปฏิบัติ Lyla หมดสติแค่ 4 ชม. ดังนั้นผ่านไป 10 ชม. เธอฟื้นไปนานแล้ว

## 9. กล่องข้อมูลล่างสุด

### 9.1 โหมดปกติ — สรุปรายระดับ Ⓐ Ⓑ Ⓒ

| บรรทัด | สูตร |
|---|---|
| **Casualty %** | คนตายในระดับนั้น ÷ คนเริ่มต้นของระดับนั้น |
| **Clear %** | **จำนวนโซนที่เคลียร์ ÷ จำนวนโซนในระดับนั้น** |
| **Zone Population %** | คนที่ยังติดอยู่ ÷ คนเริ่มต้นของระดับนั้น |

> Casualty % + Zone Population % + (คนที่ช่วยได้แล้ว %) = 100%
> Clear % เป็นตัวเลขคนละแกน (นับโซน ไม่ได้นับคน)

Ⓐ = เทา (26 โซน) · Ⓑ = เหลือง (13 โซน) · Ⓒ = แดง (8 โซน)

> ⚠️ เดิมนับ 48 โซน แต่ `map.svg` เขียน `zone-gray-03` ซ้ำทับ `zone-gray-12` สนิท
> เจ้าของยืนยันว่าเป็นโซนเดียวกัน จึงลบตัวซ้ำออก เหลือ **47 โซน (เทา 26)**

## 10. Drag & Drop

```
1. แตะไอคอนสกิลค้าง → ⏸ หยุดเวลาอัตโนมัติ
2. โซนที่ลงไม่ได้ขึ้นกากบาท ✕
3. ลากผ่านโซน → กล่องล่างเปลี่ยนเป็นข้อมูลโซนนั้น (§9.2)
4. ปล่อยบนโซนที่ลงได้ → ใช้สกิลทันที ไม่มีหน้ายืนยัน
   ปล่อยที่อื่น → ยกเลิก ไอคอนเด้งกลับ
5. หัก AP ทันทีตอนปล่อย
6. ▶ เกมเดินเวลาต่อ
```

### 10.1 เงื่อนไขปฏิเสธ (ขึ้นกากบาท ✕)

| # | เงื่อนไข |
|---|---|
| 1 | Robertson → โซนแดง (ยกเว้นตอน Last Stand) |
