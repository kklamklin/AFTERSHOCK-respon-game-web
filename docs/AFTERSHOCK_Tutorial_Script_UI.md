## หมายเหตุการปรับบท

- ตัดประโยคยาวออกเกือบหมด แทนที่ด้วยประโยคสั้น 3-8 คำ ให้ใกล้เคียงจังหวะพูดจริง
- ใส่ **"—"** ตรงจุดที่ตัวละครพูดแทรก/ตัดกันครึ่งประโยค (เช่นบีต 2, 4, 7, 9) แทนการรอให้อีกฝ่ายพูดจบก่อน
- ตัด "มุกที่ยัดเข้าไป" ออก เปลี่ยนเป็นปฏิกิริยาสั้นๆ ที่ดูเป็นธรรมชาติกว่า (เช่น "...แย่งพูดอีกแล้ว", "...พูดง่ายไปป่ะ") แทนประโยคยาวที่ฟังดูเขียนไว้ล่วงหน้า
- เพิ่มจุด **"..."** เปิดประโยคในหลายจุด สื่อถึงการลังเล/นึกคำ เหมือนคนพูดจริง ไม่ใช่อ่านบทท่องจำ
- ฉากบาดเจ็บ/จบเกม (บีต 9) ใช้ประโยคสั้นลงกว่าเดิมมาก และมีจังหวะเงียบ 2 ครั้ง เพื่อให้น้ำหนักอารมณ์มาจาก "การไม่พูด" มากกว่าคำอธิบาย
- Robertson พูดคำเดียวสั้นๆ ("รับทราบ", "พร้อมเสมอ") ไม่ใช่ประโยคเต็ม ให้สมกับที่ Lyla แซวว่า "พูดคำเดียวตลอดเลยเนี่ย"

## หมายเหตุ [จอแสดง]

- เพิ่ม stage direction **[จอแสดง]** คู่กับบทพูดทุกจุดที่หน้าจอมีการเปลี่ยนแปลงชัดเจน (สลับฉาก, ซูมแผนที่, ตัวเลข AP/เวลาขึ้น, ไอคอนเปลี่ยน state) เพื่อให้ทีมโปรดักชันรู้ว่าต้องเตรียม asset หรือ animation อะไรควบคู่กับแต่ละบรรทัด
- **บีต 1-3** อยู่ในห้องบัญชาการ (sprite เต็มจอ) — ยังไม่มีการโชว์แผนที่จริง
- **บีต 2** เป็นจุดแรกที่ตัดภาพไปแผนที่เต็มจอ เพื่อโชว์โซนสีตามที่พูดถึง แล้วตัดกลับมาที่ห้องบัญชาการในบีต 3
- **บีต 4** เป็นจุดที่ผู้เล่นเริ่ม "ลองทำเอง" ครั้งแรก (ลากไอคอนค้างบนโซนเทา) — ต้องมีกล่อง % ลอยขึ้นจริงตามบทที่ Ria พูด ไม่ใช่แค่คำอธิบายเฉยๆ
- **บีต 6-7** เป็นจุดที่ UI ตัวเลข (เวลานับถอยหลัง, จำนวนคนติดอยู่, AP) ต้องขยับให้เห็นจริงๆ ระหว่างบทพูด ไม่ใช่นิ่งอยู่กับที่ — ตัวเลขที่ขยับคือสิ่งที่ทำให้คำพูดของ Lyla/Ria มีน้ำหนัก แทนที่จะเป็นแค่คำเตือนลอยๆ
- **บีต 9** เป็นจุดเดียวที่แนะนำให้ปรับโทนภาพรวม (มืดลง/เย็นลง) ไม่ใช่แค่ sprite — เพื่อส่งความรู้สึกหนักของเนื้อหาผ่านภาพ ไม่ใช่แค่คำพูด
- **บีต 10** ปิดด้วยการเฟดเข้าเกมเพลย์จริง ควรให้ UI ที่เห็นตรงนี้ (แผนที่, AP, ตัวนับเวลา) เป็นชุดเดียวกับที่ผู้เล่นจะเจอทันทีหลัง tutorial จบ ไม่ใช่ mockup แยกต่างหาก เพื่อความต่อเนื่อง

## หมายเหตุ UI

- ทุกบีตจบด้วยปุ่ม **"Click to next"** มุมขวาล่างตามที่เห็นใน mockup
- ปุ่ม **"Skip all"** มุมขวาบนควรข้ามได้ทั้ง tutorial ในคลิกเดียว ไม่ใช่ข้ามทีละบีต
- ป้ายชื่อคงสี/กรอบตามที่ออกแบบไว้แล้ว: Ria กรอบเหลือง + "Baseplate" สีน้ำเงิน, Lyla กรอบขาว + "Field operator" สีเขียว
- Robertson ไม่มีกล่องพูดแบบ sprite ขยับปาก ใช้ portrait นิ่งของเขาโผล่มาแทน
- เนื่องจากประโยคสั้นลงมาก จำนวนบีต/คลิกต่อฉากจะเพิ่มขึ้นจากเดิม — ถ้า UI ต้องการจำกัดจำนวนคลิกทั้งหมด อาจรวมบางบรรทัดที่ติดกัน (พูดคนเดียวกัน 2 บรรทัดต่อกัน) เข้าเป็นบีตเดียวได้โดยยังคงจังหวะการพูดสั้นไว้
