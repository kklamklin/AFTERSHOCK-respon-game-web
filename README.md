# AFTERSHOCK

เกมวางแผนกู้ภัยแผ่นดินไหว · เว็บ HTML/CSS/JS · แนวนอน (Landscape) · เน้นมือถือ
ผู้เล่นเป็นผู้บัญชาการศูนย์กู้ภัย ส่ง จนท. 4 เผ่าเข้าช่วยผู้รอดชีวิต 1,200 คน ใน 48 โซน ภายใน 72 ชั่วโมง

## วิธีเปิดดูตอนพัฒนา

ต้องเปิดผ่าน server (เพราะใช้ ES modules) ไม่ใช่ดับเบิลคลิกไฟล์:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## โครงสร้างโปรเจกต์

```
index.html          หน้าหลักตอนพัฒนา (โหลด src/ เป็น module)
src/
  config.js         ตัวเลขทั้งหมดของเกม — แก้บาลานซ์ที่นี่ที่เดียว
  state.js          สถานะเกมทั้งหมด
  main.js           จุดเริ่มต้น เชื่อมทุกอย่างเข้าด้วยกัน
  styles.css
  data/operators.js  จนท. 4 ตัว + สกิล
  systems/          ตรรกะเกม (ไม่ยุ่งกับ DOM)
  ui/               ส่วนแสดงผลและอินพุต
  utils/
assets/             รูปตัวละคร / สกิล / สถานะ (ยังไม่ครบ ใส่ทีหลังทับชื่อเดิมได้)
build/build.js      สคริปต์รวมเป็นไฟล์เดียว
dist/index.html     ไฟล์สุดท้ายสำหรับส่งงาน (Base64 ฝังในตัว)
docs/               เอกสารสเปกทั้งหมด
```

## เอกสารอ้างอิง

| ไฟล์ | เนื้อหา |
|---|---|
| `docs/AFTERSHOCKMASTER.md` | เอกสารรวมฉบับหลัก |
| `docs/gamesystemfinal.md` | ระบบเกม ตัวเลข สูตร โครงสร้างข้อมูล |
| `docs/gameflowspec.md` | Flow ผู้เล่น หน้าจอ และกฎที่อัปเดตล่าสุด |

> ⚠️ กฎที่อัปเดตแล้ว: การคำนวณผลเกิด **ตอน จนท. ทำงานเสร็จ** ไม่ใช่ตอนกด Deploy
> และผลลัพธ์เหลือ 2 ระดับ (สำเร็จ/ไม่สำเร็จ) — ดู `gameflowspec.md` §1–2
