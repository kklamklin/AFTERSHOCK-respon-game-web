# AFTERSHOCKS Response

เกมวางแผนกู้ภัยแผ่นดินไหว · เว็บ HTML/CSS/JS ล้วน (ไม่มี framework · ไม่มี build step · ไม่มี backend)
ผู้เล่นเป็นผู้บัญชาการศูนย์กู้ภัย ส่ง จนท. 4 คนเข้าช่วยผู้รอดชีวิต 1,200 คน ใน 47 โซน ภายใน 72 ชั่วโมงในเกม (เล่นจริงราว 10 นาที)

**เล่นได้เลย → https://kklamklin.github.io/AFTERSHOCK-respon-game-web/**

## เล่นบนอะไรได้

- ✅ **คอม · iPad · แท็บเล็ต** — แนวนอน
- ⛔ **มือถือถูกบล็อก** (รอบ 10.28) เปิดแล้วขึ้นหน้า "ยังไม่รองรับมือถือ"
- คีย์ลัดบนคอม: `P` หยุด/เดินเวลา · `T` หน้าเวลาที่เหลือ · `Esc` เมนู · `1`–`6` เลือกสกิลแล้วคลิกโซน

## วิธีเปิดดูตอนพัฒนา

ต้องเปิดผ่าน server (เพราะใช้ ES modules) ไม่ใช่ดับเบิลคลิกไฟล์:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

push ขึ้น branch `claude/folder-structure-planning-0003vf` เมื่อไหร่ GitHub Pages อัปเดตเองใน 1–2 นาที
(Pages เสิร์ฟจาก branch นี้ตรง ๆ ไม่ต้อง merge · ต้องมีไฟล์ `.nojekyll` ที่รากเสมอ)

## โครงสร้างโปรเจกต์

```
index.html          หน้าหลัก (โหลด src/ เป็น module · มีสคริปต์ตรวจมือถือ + หน้าหมุนจอ)
soundcheck.html     หน้าตรวจเสียงสำหรับนักพัฒนา
map.svg             แผนที่ 47 โซนจริง
src/
  config.js         ตัวเลขทั้งหมดของเกม — แก้บาลานซ์ที่นี่ที่เดียว
  state.js          สถานะเกมทั้งหมด
  main.js           จุดเริ่มต้น
  styles.css
  data/
    operators.js    ทะเบียน จนท. + สกิล (ทุกไฟล์อ่านจากที่นี่ — เพิ่ม จนท. ใหม่ที่นี่)
    operatorIntel.js  ข้อมูลหน้า Intel   icons.js  sounds.js  prefs.js
    tutorialScript.js  customGame.js (เขียนทับ/คืนค่า CONFIG ของ Custom Game)
  systems/          ตรรกะเกม (ห้ามแตะ DOM): zones · time · skills · status · outcomes · successRate · danger · score · actionPoints
  ui/               แสดงผลและอินพุต: gameScreen · map · dragdrop · panels · feed · qte · hints · screens · result · devPanel ฯลฯ
  utils/rng.js      ตัวสุ่มกลาง (ตั้งซีดได้ตอนเทส)
assets/             รูปตัวละคร · ไอคอน · เพลง/เสียง
qr/                 QR code ลิงก์เกม (ถ้าเปลี่ยน URL ต้องสร้างใหม่)
tests/              เทสอัตโนมัติ (Playwright + node)
docs/               เอกสารสเปกทั้งหมด
```

## เทส

เปิด `python3 -m http.server 8123` ที่รากโปรเจกต์ แล้วรัน:

```bash
node tests/registry.mjs   # กฎเกมของทุกสกิลในทะเบียน (ไม่ต้องเปิดเบราว์เซอร์)
node tests/custom.mjs     # Custom Game + Dev Panel + หน้ารหัส Building 21
node tests/phone.mjs      # มือถือถูกบล็อก / iPad แท็บเล็ต คอมเล่นได้
node tests/newop.mjs      # เพิ่ม จนท. ใหม่ผ่านทะเบียนอย่างเดียว (ใช้กับสำเนาเกม — ดู CLAUDE.md)
```

เทสชุดเก่าอื่น ๆ (layout · devices · qte ฯลฯ) หายไปกับเครื่องเก่า ยังไม่ได้เขียนกลับมา
